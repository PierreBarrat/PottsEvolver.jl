CLI option reference

Every option of every pottsevolver subcommand. For what the options mean, and for the schedule and parameter-file formats, see Command line interface.

The tables below are generated from the CLI's own argument definitions when these docs are built, so they cannot drift from pottsevolver --help.

Each table is complete for its subcommand: the options shared by both appear in both. Every command also accepts -h/--help, which prints the same information and exits.

A default of – means the option is simply unset, which is not always the same as having no effect: the schedule options (-M, --spacing, --burnin) then fall back to the [schedule] table of the parameter file, and to the values named in their descriptions if that is absent too.

sample-chain

Sample sequences along a Markov chain

OptionArgumentDefaultDescription
modelstringrequiredPath to a Potts graph file (see read_graph)
-p, --paramsstringrequiredPath to a TOML file with SamplingParameters fields (see load_params)
-o, --outdirstringcurrent directoryOutput directory
--prefixstring–Output filename prefix (defaults to model's basename without extension)
--initstringrandom_aaOne of random_aa/random_codon/random_rna/random_num, or a fasta path optionally suffixed with ,seqname (see load_init)
--init-typestring–One of aa/codon/rna: force the sequence type read from an --init fasta path, skipping inference
--burninFloat64–For sample-chain, time before the first sample (defaults to 5 * --spacing). For sample-tree, time spent equilibrating the root sequence before sampling
--seedInt64–Integer RNG seed
-v, --verboseInt640Verbosity: <0 error, 0 warn, 1 info, >=2 debug
--log-verboseInt641Verbosity for the log file always written alongside the other outputs
--compute-omeganone (flag)offIf substitution_rate is missing from --params (continuous sampling only), compute it via average_transition_rate before sampling
--translatenone (flag)offTranslate the output to amino acids; only relevant when the initial/root sequence is a CodonSequence. Off by default: the output keeps the type that was sampled
-M, --n-samplesInt64–Number of samples taken along the chain. Combines with --spacing/--burnin and with the [schedule] table of --params; defaults to 1
--tvalsFloat64–Explicit sampling schedule (space-separated numbers), instead of -M/--spacing/--burnin. The first value is the burn-in time; later values are absolute times/steps, not deltas
--spacingFloat64–Time between samples (default 1, which is seldom enough to decorrelate). Combines with -M/--burnin, and overrides the [schedule] table of --params
--tvals-filestring–Path to a file with one time value per line, as an alternative to --tvals
